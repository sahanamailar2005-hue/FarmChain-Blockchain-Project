# FarmChain – Smart Agriculture Product Traceability

## Project Description
FarmChain is a blockchain-based agriculture product traceability system that helps track agricultural products from farmers to distributors and retailers.

## Objectives
- Maintain transparent product records.
- Track products throughout the supply chain.
- Improve trust between farmers, distributors and retailers.
- Detect missing or modified product records.

## Technologies Used
- Blockchain Technology
- Solidity
- Remix IDE
- HTML
- CSS
- JavaScript
- MetaMask

## Main Features
- Product Registration
- Product Tracking
- Product Management
- Product History
- Product Recall

## How It Works
The farmer registers a product, and its information is recorded. Distributors and retailers can update the product journey. Users can track the product history.
